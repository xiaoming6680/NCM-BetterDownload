# BetterDownload 验证记录

## 0.7.0 验证（支持网易云 2.10.x、臻音全景声）

2026-10-01：

- 33 项 Node 测试通过。新增覆盖：
  - 网易云 2.10.x 用它自带的 `legacyNativeCmder` 订阅 `storage.onaddid3done`，调用时保持原对象，不再探测 webpack；下载目录取自 `NM_SETTING_CUSTOM` 的 `storage.path`，设置缺失或损坏时为空；只有 VIP 的 NCM 进入转换；退订后不再收到事件。
  - M4A（MP4 封装）：音频按 `stco`、`stsc`、`stsz` 逐个采样取出比对，`moov` 变大后偏移仍正确；封面、标签、歌词（`©lyr`）和 `.lrc` 写入；采样条目为 `av3a`（Audio Vivid）时提示“多数播放器不支持臻音全景声”，普通 AAC 不提示；“查找并转换”跳过已有同名 `.m4a` 的歌曲。测试素材 `tone.m4a` 由 `tone.flac` 用 ffmpeg 编成 AAC，Audio Vivid 用改写采样条目类型模拟。
  - 无法识别的音频报“无法识别的音频格式”；标签写入失败的提示为“封面与歌曲信息未写入”。
- 对照网易云 2.10.13 官方安装包里的前端代码核对。安装包为 `NeteaseCloudMusic_Music_official_2.10.13.202675_32.exe`，来自网易云 CDN `d1.music.126.net`，也就是 DowngradeOK 插件使用的地址，SHA256 为 `45f8aa74a4bae7b253fe370a129f3fe22cedb8b24e3c06d04c772dd41486ffb2`。只解包查看，没有安装。
  - `pub/core.js` 用 `storage.addid3` 写入标签。完成后原生回调 `storage.onaddid3done(任务 ID, 1, 相对路径)`，路径相对下载目录，失败时为 `0`，与 3.x 相同。VIP 歌曲的相对路径以 `VipSongsDownload\` 开头。
  - 下载目录是 `NM_SETTING_CUSTOM` 的 `storage.path`，网易云自己就用它拼出完整路径。`APP_CONF.domain` 为 `https://music.163.com`，歌词接口可用。
  - `window.legacyNativeCmder` 由网易云前端自己定义。win32 下 `LegacyHacker` 会改写 `channel.registerCall`，网易云原有的处理和 `legacyNativeCmder` 上的监听分开存放、都会触发。
- 用 2.10.13 原版代码模拟：取出原版 `LegacyHacker` 和 `legacyNativeCmder`，按 `core.js` 的方式注册网易云原有处理，再模拟原生回调。
  - 无论网易云和插件谁先注册，网易云原有处理、BetterDownload 和另一个 `legacyNativeCmder` 监听都收到了每次完成事件。
  - 插件只把 VIP 的 NCM 加入转换。退订后网易云不受影响。
  - 去掉 `LegacyHacker` 后同一模拟失败，网易云原有处理被顶掉。说明这个模拟能发现这类问题。
- Edge + Playwright 界面回归通过，新增：
  - 设置页图标在网易云 2.10.x 的全局样式 `svg{width:100%;height:100%}` 下仍是原尺寸（logo 28px、行首图标 14px、功能图标 16px）。去掉修复时这项检查失败。
  - 卡片宽 290px；完成时的提示与“打开文件夹”在同一行，不增加卡片高度；14 个字的提示完整显示；连续转换时“本轮 N 首”和按钮不收缩，只截短提示，悬停显示全文。
  - 完成时显示“转换完成”，有歌词时为“转换完成 · 含歌词”。
- 真实客户端验收（网易云 2.10.13 + BetterNCM 1.3.3，作者本机隔离运行）：
  - 环境：2.10.13 官方安装包解压到单独文件夹运行，BetterNCM 数据目录用 `BETTERNCM_PROFILE` 指到测试目录；测试期间把 3.x 的用户数据文件夹改名挪开，测完改回。注册表前后对比，只有 Windows 自动记录的程序名称缓存和托盘图标等，没有网易云相关改动。2.10.13 扫码登录正常。
  - 插件加载，找到 2.10 接口，下载目录为 `E:\CloudMusic`。
  - 作者下载 5 首 VIP 歌曲：16bit FLAC、24bit/96kHz Hi-Res FLAC、24bit/44.1kHz FLAC 和 320k MP3。下载完成后约 1 秒自动转换；音频帧与独立解密的原始数据逐字节一致，ffmpeg 完整解码无错误；标题、歌手、专辑、曲目号和 960×960 封面已写入。
  - 歌词：内嵌歌词全部带时间轴，翻译与原文同一时间（如 145 行中 66 行为翻译），`.lrc` 为带 BOM 的 UTF-8 和 CRLF，与内嵌一致；纯音乐（接口返回 `pureMusic`）不写入。
  - 卡片：转换中、正在获取歌词、已完成；连续转换显示“第 1 首 · 还剩 1 首”和“本轮 2 首”；4 秒后收起；“打开文件夹”打开 `VipSongsDownload\unlock`。
  - 关闭插件期间下载的 2 首不转换、不弹卡片、不启动转换程序；重新打开后“查找并转换”补转成功。此前的 4 首按 `unlock` 里的同名文件识别为已转换。

  - 设置页功能图标被网易云 2.10 的全局样式撑大，已修复，见上文。
  - 2.10 的音质选项里没有“臻音全景声”，2.10 上不会出现 M4A。
- 真实客户端验收（网易云 3.1.37 + BetterNCM 1.3.4）：
